# Arelith Plugin Reference

## Description

Plugin dedicated to assorted Arelith-specific functionality, including implementation dependent functions and custom events.

## Environment Variables

| Variable Name | Value | Notes |
| ------------- | :---: | ----- |
| `NWNX_ARELITH_HOLY_AVENGER_TRANSITION_GUARD` | true/false | Default false. Skips the engine's Holy Avenger on-hit dispel while the target has an effect tagged `TransitionProtection` (area transition protection from `gs_a_enter`). |
